SHIFT CHALLENGE (Fabric 1.20.1, client-side)

Build:
  1. Install JDK 17
  2. Di folder ini jalankan:  gradle build
  3. Jar ada di build/libs/shiftchallenge-1.0.0.jar -> taruh di folder mods
     (butuh Fabric Loader + Fabric API 1.20.1)

Hotkey (bisa diganti di Options > Controls > Shift Challenge):
  K = buka menu pengaturan (target, waktu, preset)
  J = mulai / stop challenge pakai setting terakhir

Command (opsional):
  /shiftchallenge start [target] [detik]
  /shiftchallenge stop

Setting & rekor tersimpan di config/shiftchallenge.properties
